# Git Repositories Homework

This public repository demonstrates the essential local and remote Git workflow requested in the assignment. The repository itself is the practical evidence: its files and commit history were created with Git, published to GitHub, synchronized with a remote, and cloned for verification.

## Student

- GitHub: `abuammer-051`

## Assignment checklist

- [x] Set up and initialize a repository
- [x] Work with a Git repository
- [x] Demonstrate untracked, staged, modified, and committed file states
- [x] Use `git init`, `git add`, `git commit`, and `git status`
- [x] Save files in Git
- [x] Add a GitHub remote named `origin`
- [x] Push and set the upstream branch
- [x] Fetch and pull remote changes
- [x] Clone the public repository and verify it

All local and remote exercises have been completed. See the records in [`evidence/`](evidence/).

## Repository contents

- `docs/01-local-repositories.md` — local repository concepts and commands
- `docs/02-remote-repositories.md` — remotes, push, pull, fetch, upstream, and clone
- `evidence/` — recorded command results from the practical exercises
- `examples/hello.txt` — a sample file used to demonstrate Git file states

## Quick start

```bash
git clone https://github.com/abuammer-051/git-repositories-homework.git
cd git-repositories-homework
git status
git log --oneline --graph --decorate --all
```
